# get-response – prototyp mapowania kolumn importu

Klikalny prototyp ekranu `add-contacts/from-file` (krok dopasowania kolumn).
Otwórz `index.html` w przeglądarce – bez builda i zależności.

## Interakcje
- **+** przy sugerowanym polu – tworzy pole własne z sugerowaną nazwą i typem i dopasowuje kolumnę.
- **Rozwijana lista (chevron)** – wyszukiwarka, lista pól (już użyte są wyszarzone), *Add custom field*, *Don't match*.
- **Add custom field** – modal „Create custom field” z wstępnie wpisaną nazwą, typem, sposobem prezentacji i opcjami z pliku.
- **Accept all suggestions** – akceptuje wszystkie sugestie naraz.
